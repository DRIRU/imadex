Connect Google Drive

One-time setup for your personal dashboard:

  1. In Google Cloud Console, create a project and enable the Google Drive API.
  2. Configure the OAuth consent screen and add your Google account as a test user.
  3. Create an OAuth client with application type Desktop app and download its JSON file.
  4. Save it as data/google-client.json inside this project's folder.

Then click below to sign in. Google will ask for read-only access to your Drive. The app indexes only the folders you add.
